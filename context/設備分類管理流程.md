# 📦 業務端可調度設備分類管理流程

本文件說明如何管理與同步 KPI Dashboard 中「業務端可調度設備」的自訂設備分類（CPAP/BiPAP、氧氣製造機、隱藏等），確保分類設定可以在不同電腦與團隊成員間保持一致。

## ⚙️ 運作原理
儀表板中的設備分類依據兩個層級運作：
1. **預設關鍵字規則**：系統會根據設備的 `產品名稱` 或 `型號`，透過關鍵字自動判定分類。
2. **手動覆寫白名單**：透過 `src/config/deviceMapping.json`，我們能強制將特定型號指派到指定分類。

## 📝 操作步驟

### 1. 於介面上進行分類設定
1. 在本地開發環境或已部署的網站上開啟 KPI Dashboard，進入設備監控頁面。
2. 在「📦 業務端可調度設備」區塊標題旁，點擊 **「⚙️ 分類設定」**。
3. 系統會自動抓取所有尚未註記或已註記的設備型號清單。
4. 在該清單中，你可以針對每一個型號的下拉選單，選擇適當的分類：
   - `預設 (Default)`：套用系統預設關鍵字。
   - `CPAP/BiPAP 呼吸器`：強制歸入呼吸器。
   - `氧氣製造機`：強制歸入氧氣機。
   - `隱藏 (不顯示)`：將無關的設備隱藏，不計入可調度設備統計。

> **注意**：當你在網頁上完成操作時，設定會「暫存」在你當下使用的瀏覽器中（localStorage）。若要將此分類永久保存並套用到所有設備，必須進行以下同步步驟。

### 2. 匯出設定檔並部署至 GitHub
為了讓這些手動分類規則能在其他電腦或讓其他同事也能讀取到，需要把設定存入專案的原始碼中。

1. 在「⚙️ 設備分類設定」視窗中，點擊上方的 **「💾 下載設定檔 (deviceMapping.json)」** 按鈕。
2. 瀏覽器會自動下載一份名為 `deviceMapping.json` 的檔案。
3. 將此下載的檔案移動至專案目錄的 `src/config/` 資料夾內，**覆蓋掉舊有的 `deviceMapping.json` 檔案**。
4. 使用 Git 將變更提交並推送至遠端：
   ```bash
   git add src/config/deviceMapping.json
   git commit -m "chore: 更新設備分類設定"
   git push origin main
   ```

### 3. 完成
一旦推送到 GitHub，接下來自動部署（如 GitHub Pages）更新後，所有的裝置只要造訪此網站，都會自動讀取 `src/config/deviceMapping.json` 內的最新設定！
